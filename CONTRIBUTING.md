# Contributing to GuardianSDS

First off, thank you for considering contributing to GuardianSDS! It's people like you that make this a robust tool for safety professionals.

## How Can I Help?
1. **Reporting Bugs:** Use the GitHub Issues tab.
2. **Feature Requests:** Suggest improvements to the AI extraction or mobile UI.
3. **Pull Requests:** 
    * Fork the repo.
    * Create your feature branch: `git checkout -b feature/AmazingFeature`.
    * Commit your changes: `git commit -m 'Add some AmazingFeature'`.
    * Push to the branch: `git push origin feature/AmazingFeature`.
    * Open a Pull Request.

Please ensure your code follows the existing style and includes tests where applicable.
