# GuardianSDS Product Roadmap 2025

Our goal is to move SDS management from a "static archive" to an "active safety partner." This roadmap outlines the development phases for our community-driven platform.

## 🟢 Phase 1: The Core Foundation (Current)
- [ ] Implement AI-OCR pipeline for 16-section GHS extraction.
- [ ] Establish centralized PostgreSQL database schema for chemical attributes.
- [ ] Create the "Emergency Mode" bypass-auth view for critical safety data.
- [ ] Deploy basic Web UI for PDF uploads and library management.

## 🟡 Phase 2: Mobile & Field Utility (Q1-Q2 2025)
- [ ] Native iPad Pro optimization (high-contrast UI for clinical environments).
- [ ] Dynamic QR Code Generator for room-specific or chemical-specific mapping.
- [ ] **GHS Label Engine:** Generate and print secondary container labels on-site.
- [ ] Offline-First caching (Service Workers) for OSHA-mandated offline access.

## 🟠 Phase 3: The Intelligence Layer (Q3 2025)
- [ ] **The Sentinel:** Automated web-scrapers to monitor manufacturer sites for SDS updates.
- [ ] **Spill-Chat:** RAG-powered voice assistant for hands-free First Aid retrieval.
- [ ] Integration APIs for hospital CMMS (ServiceNow, FSI, etc.).
- [ ] Automated "Revision Comparison" (highlighting exactly what changed between SDS versions).

## 🔴 Phase 4: Enterprise & Ecosystem (2026+)
- [ ] Multi-facility "Global View" for health system directors.
- [ ] Direct integration with chemical sensors/IoT for real-time spill alerts.
- [ ] Community-shared "Verified SDS" global index.
